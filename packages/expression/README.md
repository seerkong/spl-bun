# SPL expression

`evaluateExpression(source, scope)` is shared by table operations, Kon `spl_eval`, and Flow. Row adapters bind known schemas; a declared missing cell shadows an external variable of the same name.

Scalar `+`/`-` follow esProc Variant: null is an additive identity; numeric text plus a number is numeric addition (unparseable text contributes zero); two strings concatenate. `/` concatenates when either operand is text. Use `concat(...)` for explicit text construction. Multiplication and numeric division propagate null. Date +/- integer uses local calendar days; Date - Date counts calendar dates. Dates and sequences compare by values; incompatible ordered types fail.

Ordinary fractional literals remain IEEE doubles. Unsafe integer literals in signed 64-bit range are exact bigint; `long("9007199254740993")` converts text without rounding and wraps arithmetic at 64 bits. `decimal("0.1") + decimal("0.2")` is exact 0.3; division rounds half up to 16 decimal places, as Variant does. `decimal(number)` retains the binary double value; use text for decimal intent. Decimal values have a 2048 digit/exponent resource bound and reject oversized results. Number inputs that have already lost integer precision must be supplied as exact text.

Shared sum/avg/min/max/median and numeric tuple keys retain exact values. Distinct numeric values compare across number/long/decimal; numeric text stays distinct. JSON/CSV imports preserve unsafe integer tokens as text. Convert them explicitly with long/decimal. JSON/file and web-worker outputs serialize exact values as text, keeping browser and SQLite boundaries lossless. Plain native JSON.parse outside the shared import API and binary Excel numbers do not recover precision already lost by their producer.

No Java numeric runtime is required. decimal.js is the arithmetic vendor; its configuration is private and frozen.

`input.sort(amount*rate, category:-1; 'de_DE')` binds row expressions to the schema and outer scope. Keys project once in input order; ties retain input order. `@z` reverses all keys unless numeric per-key orders are supplied; `@0` puts null/missing keys last in either direction. `@u` preserves every row and groups equal key prefixes in encounter order; it never deduplicates. Legacy quoted expressions/columns and `sort('amount','desc')` remain supported. Primitive sequences can use `sort()` or `sort(_)`. Unknown fields/options, non-scalar keys and incompatible types fail, including schema errors on empty tables. In-place `@o` and group-number `@n` are explicitly rejected. Kon column sorting delegates to the same processor; expressions/options use `spl_eval` and Flow's shared evaluator. Locale comparison uses host Intl rather than Java's complete ICU locale database; Java class identity and signed zero follow the existing shared scalar protocol.

`parse(text)` converts booleans, null, scientific/percent/hex/long-suffixed numbers, source data-only JSON and default local date/time patterns. Explicit signed `NaN`/`Infinity` tokens, including percent forms such as `NaN%` and `-Infinity%`, produce numbers; ordinary numeric overflow still fails. `@q` retains the first quoted segment including quotes; `@qe` decodes its interior. `@e` decodes source escapes before conversion; `@n` reads an initial numeric prefix, returning null when absent, including these nonfinite tokens. Precedence is quoted q/e, then e, then n. JSON supports unquoted keys and trailing array nulls; source empty `{}` stays text. Own-property construction is safe for `__proto__`, and unsafe JSON numeric tokens stay text via the shared transport parser. Top-level signed 64-bit integers retain bigint precision; overlong integers retain Decimal rather than Java double rounding, and numeric overflow fails. Text is bounded to 1 MiB and JSON nesting to 128. Non-string inputs pass through without mutation, after option validation; unsupported options/overloads fail. Default date patterns are `yyyy-M-d`, `yyyy-M-d H:m:s`, `H:m:s` in the host's local calendar; mutable Java date format registries and Gregorian cutover are not imported. Regex capture parsing (`@p`) uses this same converter. JSON transport retains its existing encoding of nonfinite numbers; use `string(parse(text))` for an explicit display label.

`elapse(value,n)` and `dateadd(value,n)` support `@y/@q/@m/@s/@ms` (default calendar days). Month/quarter/year moves preserve month end; `@e` disables that preference and clamps the original day. `elapse(null,n)` uses the current time; `dateadd(null,n)` retains its null result.

`interval(start,end)` follows Variant's integer rules: `@y/@q/@m` count boundaries, `@s/@ms` measure time, `@w` counts whole seven-day buckets, `@1/@7` count Monday/Sunday markers, and `@ym/@ymd/@md/@yd` return packed components. `@r` gives elapsed days, or fractional unit values when combined with a unit. Source day buckets are anchored at local 2000-01-01 and use truncation, including its pre-anchor edge behavior. `datediff(end,start)` keeps elapsed days; supplying a unit delegates to `interval(start,end,unit)`. Unsupported combinations fail explicitly. The Java integer ordinal-date representation and pre-Gregorian calendar cutover are not host Date interchange formats.

Row-aware members `select`, `derive`, `calc`, `sum/avg/min/max/median/count/icount` share the invocation's function/member registry and scope. Examples: `input.derive(amount*rate:gross,gross+1:next).select(next>10)` and `input.sum(amount*rate)`. New columns are visible in order; declared sparse columns shadow outer names. Existing quoted row strings and string-valued derive maps remain supported. Map values are outer expressions that produce row-expression text; `expression:alias` carries a row AST directly and can also produce constant text. Unsupported aliases/options/parameter groups fail. Cursor select/derive apply the same row processors lazily; synchronous Kon rejects cursor operations at the actual call boundary, including nested and quoted row expressions.

`sequences.union/isect/diff/conj@m()` performs sorted merging and validates ascending inputs. Union keeps maximum multiplicity, intersection minimum, difference subtracts multiplicities, and conjunction retains every item. An optional row mapper has the same invocation scope. `conj@r()` recursively flattens and skips nulls; cyclic arrays, depth >128, and outputs >1,000,000 elements fail. Full Java recursive derive/multithread/locale overloads remain separate from this row-expression protocol.

`windowTable(table,spec,scope)` is the pure implementation behind `DataSet.window`, table `.window(spec)`, and Kon `spl_window`. Existing rank/running outputs retain their declarations. `lag`/`lead` are lists of `{column or expression, as, offset=1, defaultValue=null}`; offsets never cross partitions. `frames` is a list of `{kind, column or expression, as, start, end}`. Bounds are inclusive relative row offsets; `start=null`/`end=null` means the partition edge. Example: `{kind:'sum',column:'amount',as:'last_three',start:-2,end:0}`. Reversed/outside frames are empty; count gives 0 and other empty numeric aggregates give null. Null values do not increase average denominators, exact numeric sums stay exact, and unused out-of-range expressions are not evaluated. These materialized ROWS frames do not claim SQL RANGE/GROUPS or external spill execution.

`format(pattern,...values)` now implements the common Java Formatter protocol: `%s/%b/%c`, decimal/octal/hex integers, `%f/%e/%g`, argument indexes and `<` reuse, flags/width/precision, `%%/%n`, and common `%t` date components. Exact long/decimal values format without Number conversion. The legacy `format(date,'date'|'iso')` aliases remain. `string(value,pattern,locale?)` supports common Java date patterns and ICU-style decimal grouping/fractions/percent/negative subpatterns; `number(text,fallbackOrPattern?)` parses numeric text or a formatted number, with a numeric fallback. `string@u/@e/@q` encode Unicode/escapes/quotes for string inputs. Unknown overloads, flags, conversions or pattern letters fail explicitly. Width is bounded at 10,000 and precision at 1,000.

Host adaptations remain explicit: numeric `number` values do not preserve Java Integer/Double class identity; text `%c` accepts one character because JS has no Character type. Default Date text is ISO, and localized month/weekday/zone names use Intl rather than Java's locale database. Full Formatter object hashes/hex floats, arbitrary DecimalFormat grammar, and Java calendar cutover behavior are outside this finite format protocol.
