# 来源语义与显式转换吸引子

本文件用不变量界定合法结构。文档是载体；代码与测试是可重建投影。

## 一句话方程

`output = pureProcessor(input, config); inputAuthority -> derivedOutput; adapter -> sharedSemantics`

## 原语

源 Java 是外部语义证据；旧记录是历史承诺；输入表/词法文本是本次事实；转换结果是派生值；宿主 IO 只在现有 support。

## 硬不变量

- I1 单一规则：✅ 各入口复用同一纯转换；❌ Kon/flow 复制一个相似但不同的语义引擎。
- I2 输入权威：✅ 新行/新日期/新值，不反写输入；❌ 计算改变原记录或外部作用域。
- I3 显式失败：✅ 不支持的类型、选项或缺字段有明确诊断；❌ 静默吞参数或精度损失。
- I4 依赖单向：✅ vendor 原语封装在逻辑层，IO 在宿主；❌ 引入 Java runtime、企业平台、全局可变运算配置。

## 排除集

静默丢精度、未选分支有副作用、声明字段回退到外部同名值、无验证的兼容声明、源仓库回写。

## 与 harness

MISSION 定义终点，loop 是执行图，evidence 记录度量；本文件仅定义合法结构，不复制工作图。
